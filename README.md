# stridestore-webshop
schoolproject - webshop met publieke frontend en admin backend (HTML/CSS)
StrideStore – Webshop Project
StrideStore is een fictieve webshop voor sneakers die ik heb gemaakt voor het vak HTML/CSS. Het doel van het project was om een volledige webshop te maken met een publieke website en een apart administratief gedeelte.
Op de publieke website kunnen bezoekers de producten bekijken en verschillende productdetailpagina's openen. In het /admin-gedeelte kan de beheerder de voorraad en producten beheren.
Plan van aanpak en timing
Ik heb het project verspreid over drie dagen. Op die manier kon ik stap voor stap aan de verschillende onderdelen werken.
Dag 1 – Zaterdag
Op de eerste dag heb ik de basis van de website gemaakt.
* Ik heb een GitHub-repository aangemaakt en deze gekoppeld aan mijn lokale project in Visual Studio Code.
* Ik heb de basisstructuur van index.html gemaakt met onder andere de head, Google Fonts en de koppeling met mijn CSS-bestand.
* Daarna heb ik de navigatie gemaakt met het logo en de verschillende links. Hiervoor heb ik Flexbox gebruikt.
* Vervolgens heb ik een hero-sectie toegevoegd met een titel, tekst, knop en afbeelding.
* Ik heb een productgrid gemaakt met 6 sneakers. Elk product bevat een afbeelding, naam, prijs en knop.
* Bij 3 producten heb ik een label toegevoegd, zoals "Nieuw", "Sale" en "Limited Edition".
* Ik heb ook een extra gedeelte "Waarom StrideStore" toegevoegd met 4 voordelen.
* Als laatste heb ik de footer gemaakt met contactgegevens, categorieën en copyrightinformatie.
Dag 2 – Zondag
Op de tweede dag heb ik vooral gewerkt aan de productpagina's en het admin-gedeelte.
* Ik heb product.html gemaakt als detailpagina voor een sneaker.
* Op deze pagina staan een grote foto, beschrijving, specificaties, klantreviews en gerelateerde producten.
* Daarna heb ik product-2.html en product-3.html gemaakt. Deze pagina's bevatten andere producten zodat de website meer als een echte webshop aanvoelt.
* Ik heb de links op de homepage aangepast zodat elk product naar de juiste detailpagina gaat.
* Daarna heb ik de volledige /admin-map gemaakt.
Het admin-gedeelte bestaat uit:
* login.html: een eenvoudig en gecentreerd inlogscherm.
* dashboard.html: een overzicht van de producten en de voorraad. Hier staan onder andere het ID, de naam, voorraadstatus, prijs en acties.
* product-form.html: een formulier waarmee een beheerder een product kan toevoegen of aanpassen.
* admin.css: een aparte stylesheet voor het admin-gedeelte. Ik heb bewust voor een andere, meer zakelijke stijl gekozen dan voor de publieke website.
Tot slot heb ik responsive CSS toegevoegd. Ik heb zelf een breakpoint van 900px gekozen zodat de website ook goed werkt op kleinere schermen.
Dag 3 – Maandag
Op de laatste dag heb ik vooral alles gecontroleerd en afgewerkt.
* Ik heb de README geschreven.
* Ik heb alle pagina's getest.
* Ik heb gecontroleerd of alle links correct werken.
* Ik heb de website ook op een kleiner scherm getest.
* Kleine fouten in de code en styling heb ik verbeterd.
* Daarna heb ik de laatste commits gemaakt en gecontroleerd of alles correct op GitHub stond.
Gebruikte technologieën
Voor dit project heb ik de volgende technologieën gebruikt:
* HTML5 – voor de structuur van de website.
* CSS3 – voor de styling en layout.
* Flexbox – voor verschillende onderdelen van de layout, zoals de navigatie, productgrid, hero-sectie en footer.
* Google Fonts – ik heb Poppins gebruikt voor titels en Inter voor gewone tekst.
Ik heb ook semantische HTML-tags gebruikt, zoals header, nav, section, article en footer.
